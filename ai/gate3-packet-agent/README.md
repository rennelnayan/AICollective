# Gate 3 Packet Agent

> **STUB. Not yet specified.** This agent is named in the planned repository
> structure, but no requirements, instructions or flow exist for it.

## What is known

Nothing beyond the name. Gate 3 in the current workflow is the committee
decision for cases reaching the High or Prohibited band, or where mandatory
enhanced due diligence applies under 31 CFR 1010.610(c).

## What needs deciding before this can be written

1. **What the agent produces.** A committee memo? A packet? Both?
2. **What it reads.** The scoring output, the Gate 1 packet, the Gate 2
   assessment record, or all three?
3. **Its boundaries.** The intake analyser is forbidden from scoring or
   approving. What is the equivalent constraint here? Drafting a memo that
   recommends an outcome is materially different from drafting one that
   presents the facts.
4. **Where the human sits.** Gate 3 is a committee, not an individual. What is
   the decision record, and who signs it?

Point 3 is the one to settle first. It determines everything else.
